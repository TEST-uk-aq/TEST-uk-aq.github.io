About the data

National emissions inventory

Data are derived from the UK National Atmospheric Emissions Inventory. UK AQ preserves missing values as missing rather than treating them as zero, and excludes memo/non-additive records from normal grouped totals.

The Explorer uses the latest published UK AQ NAEI dataset. Historical and current source files are retained with the published dataset for provenance.
